# 유니파인더 UNIFINDER

## 1. 프로젝트 소개
- 특정 조건에 맞는 대학 수시 전형을 검색할 수 있는 웹 서비스
- 기존에는 대학의 정보를 모아서 볼 수 있는 "대학 어디가"사이트가 있지만 대학 간 비교가 가능할 뿐 전형간 비교는 불가능함 -> 전형 정보를 정규화하여 각 전형을 비교검색할 수 있게 함

## 2. 프로젝트 구조
- Next.js 14
- Tailwind CSS
- Recoil
- Auth.js
- SWR
- PostgreSQL
